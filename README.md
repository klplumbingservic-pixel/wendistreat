# Wendis Treat: Lagos Culinary Gem

Create a modern, premium website for a Lagos-based food brand called Wendis Treat. The design should feel fresh, classy, and appetizing, with smooth animations and an easy-to-use interface.

🎨 Design Style (Premium Red Theme):

Color palette: Deep Red (#8B0000), Soft Cream (#F8F5F0), Warm Orange (#F4A261), and Gold accents

Clean, elegant, and slightly bold luxury feel

Smooth micro-animations (hover effects, fade-ins, sliding sections)

Mobile-first responsive design

Rounded UI elements for a friendly but premium look

🏠 Homepage Sections:

Hero Section

Headline: “Delicious Meals, Made Fresh Every Day”

Subtext: “Serving quality food in Lagos from 8AM to 6PM”

CTA buttons: “Order Food” and “Book Now”

Background: high-quality Nigerian food images

About Section

Short story about Wendis Treat

Focus on freshness, hygiene, and taste

Availability & Location

Monday to Saturday (8AM – 6PM)

Address: Kosofe Complex, Ogudu Road, Lagos State

Add map integration

Featured Meals

Show popular Nigerian dishes (rice, swallow, soups, snacks)

Include images, short descriptions, and prices

Button: “Explore Full Menu”

🍽️ Menu Page (IMPORTANT):

Create a beautiful and easy-to-use food ordering menu:

Categories: Rice Dishes, Swallow & Soups, Proteins, Snacks, Drinks

Each item should have:

Image

Name

Description

Price

Allow users to:

Select items

Add to cart

View order summary

CTA: “Order via WhatsApp”

📅 Booking Page:

Create a simple and smooth reservation/booking system:

Fields:

Full Name

Phone Number

Date

Time

Number of people

Option: Pickup or Dine-in

Submission sends details via WhatsApp or email

📸 Additional Sections:

Gallery (clean grid of Nigerian meals)

Customer Reviews (testimonials)

Why Choose Us

Fresh ingredients

Fast service

Affordable luxury meals

Contact Section

Phone number

WhatsApp button

Social media icons

⚡ Features:

Sticky navbar

Floating WhatsApp chat button

Smooth scrolling animations

Fast loading speed

SEO-friendly structure

💎 Overall Goal:

Make the brand feel like a premium, vibrant Lagos food spot — bold, appetizing, and designed to convert visitors into paying customers fast.
